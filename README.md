# 🃏 Гра "Дурень" (Durak Game)

![Version](https://img.shields.io/badge/version-1.0.0-blue)
![License](https://img.shields.io/badge/license-MIT-green)
![Platform](https://img.shields.io/badge/platform-Windows-lightgrey)

Ласкаво просимо в репозиторій класичної карткової гри "Дурень"! Це комп'ютерна реалізація популярної гри з інтелектуальним суперником та зручним інтерфейсом.

## Опис
Проєкт являє собою консольну аплікацію, що дозволяє грати в "Підкидного дурня" проти комп'ютера. Гра розроблена з використанням C++ та SFML.

## Особливості (Features)
- 🎮 Режим гри: Гравець проти Комп'ютера (AI).
- 🧠 Розумний бот: Комп'ютер аналізує карти на столі та приймає оптимальні рішення.
- 🃏 Колода: Класична колода на 36 карт.
- 🔄 Логіка: Повна реалізація правил "Підкидного дурня".

## Як встановити та запустити
Щоб програма успішно знайшла всі текстури та шрифти, будь ласка, створіть на своєму диску папку C:\SFML\ і скопіюйте туди всі графічні ресурси (.png) та файл шрифту (.ttf) з цього репозиторію перед компіляцією.
4. Насолоджуйтесь грою!
