## Опис
Проєкт являє собою консольну аплікацію, що дозволяє грати в "Підкидного дурня" проти комп'ютера. Гра розроблена з використанням C++ та демонструє роботу з .....

## Особливості (Features)
- 🎮 Режим гри: Гравець проти Комп'ютера (AI).
- 🧠 Розумний бот: Комп'ютер аналізує карти на столі та приймає оптимальні рішення.
- 🃏 Колода: Класична колода на 36 або 52 картами.
- 🔄 Логіка: Повна реалізація правил "Підкидного дурня".
- 📊 Статистика: Підрахунок кількості перемог та поразок.

## Як встановити та запустити

### Для користувачів (Windows)
Щоб просто пограти, вам не потрібно встановлювати середовище розробки.
1. Перейдіть у розділ [Releases](../../releases) цього репозиторію.
2. Завантажте архів Durak-v1.0.zip або інсталятор DurakSetup.exe з останнього релізу.
3. Розпакуйте архів та запустіть файл Game.exe.
4. Насолоджуйтесь грою!
